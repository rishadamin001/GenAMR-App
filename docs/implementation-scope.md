# Research prototype scope

Implemented: Next.js 16 / React 19 / Tailwind 4; desktop workstation and mobile navigation; language and currency controls; six selectable cases and 60 historical fixtures; sample registration, scannable QR labels and SLA countdown; logistic qPCR traces, gene/Ct controls, plate display and simulated melt table; fast/reflex routing; high-DPI Sanger traces, horizontal zoom/scroll and mutation controls; printable 16-drug synthetic report; AST reconciliation with computed denominators; eight-division summaries and CSV/JSON downloads; optional private Supabase uploads; offline app shell and PNG installation icons.

Intentional scientific limits: the app does not claim validated diagnostic performance, fitted/calibrated ML, confirmed partnerships, measured mortality/AMR rates, or clinical susceptibility based on gene absence. It is an ideathon demonstration. Fixed probability scores and model-weight changes are illustrative. The VME reduction requested in the brief is labeled an unverified target. EUCAST/CARD/ResFinder references are provenance for future curation, not a claim of a complete ruleset. No real AB1 decoding, full allele identification, lab-validated primers, or official GLASS submission mapping is implemented. Primer lengths for unvalidated demo loci must not be used as laboratory instructions. Hospital profiles and regional assignments are synthetic.

Operational limits: the service is not ready for real patients or a commercial clinical rollout. Supabase live policy tests require a project. The demo permits no destructive cloud operations. A fresh browser does not automatically upload seed data; local edits trigger serialized sync only when connected and authenticated. Vercel Hobby is intended for personal non-commercial projects; this deployment target is the ideathon demo, not the proposed hospital business.

Sources consulted: Next.js official v16 documentation via Context7; React official effect/cleanup docs; Tailwind official v4 upgrade guide; Supabase row-level security documentation; EUCAST expert rules; Vercel Hobby documentation. Installed package security was checked independently because Context7's listed Next.js patch was behind published advisories.
